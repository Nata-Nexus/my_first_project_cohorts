# Когортний аналіз та Retention (SQL / Google Sheets)
Когортний аналіз та Retention (SQL / Google Sheets)

Tools: PostgreSQL, SQL, Google Sheets.

Description: Дослідження життєвого циклу користувачів та порівняльний аналіз показників утримання (Retention Rate) для промо- та органічного трафіку з розробкою стратегічних рекомендацій для бізнесу.

Tasks:Проаналізувала, очистила та уніфікувала текстові формати дат у сирих таблицях за допомогою регулярних виразів (~) та функцій конвертації (to_date).Об'єднала великі таблиці користувачів та подій за допомогою оператора JOIN, відфільтрувавши технічні логи.
Згрупувала користувачів у когорти за місяцями реєстрації та розрахувала тривалість їхньої активності (month_offset).
Побудувала зведені таблиці (Pivot Tables) та налаштувала теплові карти (Heatmaps) в Google Sheets для порівняння сегментів користувачів.
Провела детальний аналіз поведінки когорт, виявивши аномалії та ключові точки відтоку клієнтів.

Results:Виявила протилежні тренди: при зниженні обсягів залучення органічних користувачів на 27%, їхній рівень утримання зростає (до 87-92% на 1-2 місяці).
Визначила критичну проблему промо-трафіку: попри активне залучення, відбувається різкий відтік клієнтів у перший місяць (падіння Retention до 32-50%) через одноразове використання промокодів.Сформувала 3 комплексні бізнес-рекомендації: зміна моделі знижок на накопичувальний кешбек (10-15%), масштабування залучення через таргет на основі профілю лояльних когорт, та налаштування автоматичних ретаргетинг-нагадувань на 14-й день.
