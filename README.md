# Когортний аналіз та Retention
Когортний аналіз та Retention
(https://docs.google.com/spreadsheets/d/1EtupfXauQGSFUhgJCdu3QvS9KYMCemQJgSbSRSc5QoI/edit?gid=836683059#gid=836683059))

Інструменти: PostgreSQL, Google Sheets.

Опис: Дослідження життєвого циклу користувачів та порівняльний аналіз показників утримання (Retention Rate) для промо- та органічного трафіку з розробкою стратегічних рекомендацій для бізнесу.

Завдання:Проаналізувала, очистила та уніфікувала текстові формати дат у сирих таблицях за допомогою регулярних виразів та функцій конвертації.Об'єднала великі таблиці користувачів та подій за допомогою оператора JOIN, відфільтрувавши технічні логи.
Згрупувала користувачів у когорти за місяцями реєстрації та розрахувала тривалість їхньої активності.
Побудувала зведені таблиці та налаштувала теплові карти в Google Sheets для порівняння сегментів користувачів.
Провела детальний аналіз поведінки когорт, виявивши аномалії та ключові точки відтоку клієнтів.

Результати:Виявила протилежні тренди: при зниженні обсягів залучення органічних користувачів на 27%, їхній рівень утримання зростає (до 87-92% на 1-2 місяці).
Визначила критичну проблему промо-трафіку: попри активне залучення, відбувається різкий відтік клієнтів у перший місяць (падіння Retention до 32-50%) через одноразове використання промокодів.Сформувала 3 комплексні бізнес-рекомендації: зміна моделі знижок на накопичувальний кешбек (10-15%), масштабування залучення через таргет на основі профілю лояльних когорт, та налаштування автоматичних ретаргетинг-нагадувань на 14-й день.
